## Design decisions

- Keep the logo and its purple `#693693`, cyan `#1D9FD9`, off-white `#FCFCFC`, and ink `#0D0E10` palette.
- Use a consistent, self-hosted sans-serif font, larger reading text, and fewer small uppercase labels.
- Use open columns, fine separators, wide imagery, and selective diagonal details from the logo.
- Give each page one clear purpose and primary action. Keep detailed program and project information on separate pages.
- Replace repeated boxed panels with concise editorial sections. Keep forms and selected feature areas visually distinct.
- Use a shorter homepage, filterable program archive, a featured project story with sourced outcomes, a focused partnership enquiry, and native expandable questions on Join.
- Preserve responsive navigation, visible keyboard focus, reduced-motion preferences, and lightweight interactions without adding dependencies.

## Content and assets

The exported mockups include unverified member identities, project names, active cohorts, acceptance rates, funding promises, partner endorsements, and physical hubs. The implementation instead uses the existing documented Umojaverse programs and published outcomes. Archived events stay clearly labelled as past events.

The default community destination remains the verified X profile. The enquiry form prepares a message for the visitor to share and does not claim to send it automatically.

The original illustrative screenshot crops have been replaced on the website with three real Arbitrum Pulse Ethiopia photos from the owner's local event collection. See `photos/README.md` for their source filenames and placements. Event attribution keeps Ethiopia photography separate from the Kenya program outcomes.

Original Stitch exports are preserved in their folders.
